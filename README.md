# GEH Lab · Plant Analyzer

충남대학교 시설환경원예학연구실의 식물 분석 워크스페이스입니다. 한국어와 영어로 흡광도 11종, HPLC, 켈달 질소 분석, LI-6800 가스 교환 및 FP100 엽록소 형광 측정을 사용할 수 있습니다.

## 실행 및 배포

Node.js 22에서 검증했습니다. 압축을 풀고 `package.json`이 있는 디렉터리에서 실행합니다.

```sh
npm ci
npm run dev
```

`npm test`로 수치 및 파일 처리 테스트를, `npm run lint`로 정적 검사를 실행합니다. `npm run build`는 배포 파일을 `dist/`에 생성합니다. `npm run preview`로 빌드본을 열 수 있습니다.

Vercel의 프로젝트 루트는 `package.json`이 있는 폴더이며, 프레임워크는 Vite, 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다. `vercel.json`에는 분석 페이지 주소를 직접 열기 위한 SPA 경로 설정이 포함돼 있습니다.

## 실험 데이터

[프로토콜 검토 기록](PROTOCOL-REVIEW.md)에서 분석별 근거 문헌, 적용 범위, 계산에 필요한 조건을 확인할 수 있습니다.

- **흡광도**는 파장별 측정값을 직접 입력하거나 ‘파일 업로드’에서 Epoch/Gen5 원본 Excel(.xlsx)과 CSV 양식을 읽습니다. 엑셀 미리보기에서 워크시트, 판독 채널·회차, 웰 역할과 처리구를 확인한 뒤 추가합니다. 다른 분석 화면에서 파일을 열면 판독값에 맞는 분석으로 전환할 수 있습니다. 항목별 도면에서 측정 원리와 파장을 확인할 수 있습니다. 총 페놀·총 플라보노이드·과산화수소의 표준용액 계산기는 입력한 목표 농도에 따라 원액의 분주량 그래프와 희석액 배합을 다시 그립니다.
- 분석법마다 식물 조직과 측정 원리 모식도, 시약 제조법 및 보관 주의가 함께 표시됩니다. 흡광도 신뢰성 표는 파장별 AU의 점검 구간을 보여줍니다. CAT·POD의 반응속도 또는 파장 간 차이에는 이 구간을 적용하지 않습니다.
- 엑셀의 표준 농도와 흡광도가 있으면 미리보기에서 검량선 기울기와 절편을 자동으로 채웁니다. 장비의 선형 검량식만 있을 때는 선택한 신호와 연결되는 식을 사용합니다. 근거가 부족하면 이유와 직접 입력 경로를 보여줍니다. 시료를 가져오면 해당 파일의 계수가 저장되고 기존 시료에는 이전 검량선이 유지됩니다. 웰별 측정값과 처리구 편집은 미리보기에서 펼칠 수 있습니다.
- 같은 웰의 기술 반복은 회차를 선택하거나 평균을 구합니다. CAT·POD는 지정한 관측 구간의 기울기(ΔA/min)를 사용합니다. DPPH의 SPL/SPLC 짝과 SOD의 Light/Dark 대조값은 확인 후 적용합니다. 가져온 시료의 원본 파일과 계산 조건은 시료 수정 화면과 CSV에서 확인할 수 있습니다.
- **MDA**는 600 nm의 비특이적 흡광도를 532 nm 측정값에서 뺀 다음, 몰 흡광계수 155 mM⁻¹ cm⁻¹와 광경로 길이로 나눕니다. 최종 반응액의 MDA 환산 농도(μM)를 보고합니다. 기본 광경로는 1 cm이며 계산 조건에서 변경할 수 있습니다. 실험법 원문은 `public/protocols/mda.pdf`에 있습니다.
- **HPLC**는 머무름 시간과 면적을 읽어 피크를 검토한 뒤 정량합니다. 텍스트 PDF와 CSV·TSV는 브라우저에서 처리합니다. 로컬 추출이 어려운 PDF는 해당 파일의 외부 전송 버튼을 선택하면 기존 Base44 서비스로 전달됩니다. 이 선택 기능은 연결된 서비스의 가용성과 권한에 따라 동작합니다.
- **켈달 질소**는 시료와 공시험의 적정량, 산의 노르말 농도와 건조 시료 무게를 사용합니다. **LI-6800**은 측정 로그의 A와 Qin 또는 Ci를 산점도와 표로 표시합니다.

- **FP100**은 FluorPen OJIP 텍스트와 LC·NPQ 원본 엑셀(.xlsx)을 읽습니다. LC·NPQ 엑셀에서는 기록된 프로토콜, 측정별 형광 시계열과 장비 산출 지표를 불러옵니다. LC3와 NPQ2는 실제 장비 파일로 검증했습니다. OJIP는 헴프 연구와 장비 설명서의 O·I 시점을 선택해 정규화 곡선과 JIP 지표를 계산할 수 있습니다. 장비 가이드에는 OJIP, LC1–3, NPQ1–2, Ft, QY, PAR, Multi/Repeat의 측정 순서, 모식도, 후속 분석과 매뉴얼 페이지가 있습니다.

흡광도와 HPLC의 **시각화** 탭은 막대그래프·점그래프·박스플롯·히트맵을 제공합니다. 막대와 점은 처리구 평균(±SE)이나 개별 시료값을 표시합니다. 박스플롯은 사분위 범위와 중앙값, 1.5 IQR 기준의 수염과 이상치를 표시합니다. 히트맵은 시료별 지표 또는 화합물을 열로 펼치고 각 열의 값 범위로 색을 정합니다. 화면의 그래프는 SVG로, 처리구 통계나 히트맵 행렬은 CSV로 저장할 수 있습니다. 측정값이 없을 때 선택할 수 있는 예시는 브라우저 실험 데이터에 저장되지 않습니다.

LI-6800 가이드 8개 항목과 켈달 실험 3단계에서는 항목을 열면 원본 사이트에서 사용하던 YouTube 재생기가 표시됩니다.

흡광도 시료와 HPLC 정량 작업은 현재 브라우저의 사이트 저장 공간을 사용합니다. 데이터를 다른 장치에서 사용할 때는 CSV로 내보내세요. 메인 화면에서 사용할 장비를 선택하면 해당 분석 도구가 바로 열립니다.

## 디자인 자료

바질·대마·배초향·노지·상추·쑥속 식물 사진과 연구실 로고는 제공된 GEH Lab 아카이브에서, 장비 사진과 실험 단계 이미지는 Plant Analyzer 아카이브에서 가져왔습니다. 메인의 사진은 6초마다 전환되며 일시정지와 수동 이동을 지원합니다. 기기의 동작 줄이기 설정이 켜져 있으면 수동으로 시작합니다. 검색 다이얼로그와 입력 컨트롤에는 기존 shadcn/ui를 사용합니다. 메인 사진 위의 반투명 패널에서 다섯 장비로 바로 들어갈 수 있습니다. 상단 화면 설정에서 시스템 모드·라이트·다크와 글자 크기(85–150%)를 선택하면 같은 브라우저의 모든 화면에 적용됩니다. 장비 안내와 결과 화면에서는 선택한 항목의 도면·사진·측정값을 가까이 배치하고 항목을 변경할 때 짧게 전환합니다.
